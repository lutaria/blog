# 审稿清单

用于审阅新文章或文章修改。审稿人给出反馈，不替作者改观点、论证或可发布正文，也不代替作者决定是否发表。

## 事实与引用

- 事实、数据、日期和引用是否可核实，是否给出可访问的来源。
- 是否出现作者未经历却被写成亲历的内容。
- 外部链接是否仍可访问，链接文字是否说明去向。
- 标题与摘要是否准确概括正文，没有夸大结论。

## 代码与图表

- 代码示例是否可运行，导入路径和命令是否与当前仓库一致。
- 共享代码或流程图是否从 `shared/` 直接读取，而不是文章内复制。
- 代码块语言标注是否正确，复制按钮、高亮主题和文件名是否正常。
- Mermaid 图是否能在严格模式下渲染，失败时是否保留可读源文本。
- 图表、图片的说明是否与正文一致，替代文本是否描述了实际内容。

## 语言与无障碍

- 中文标题、摘要、正文与目录条目是否标注 `lang="zh-CN"`，英文界面、日期和按钮是否保持 `en`。
- 标题层级是否从 `h1` 开始且不跳级；目录链接是否指向真实标题。
- 键盘操作是否完整：Enter 提交搜索、`q` 参数保留、Clear 清除、Retry 只在真实失败时出现。
- 颜色对比度、焦点样式与移动端横向滚动是否仍符合现有站点行为。

## 构建与搜索

- `npm run check` 与 `npm run build` 是否通过。
- 有公开文章时 Pagefind 索引是否生成，搜索、结果跳转与空态是否正常。
- 全部文章为草稿时构建是否成功，搜索页是否显示空态且不请求 Pagefind、不显示 Retry。
- 首页、标签页、RSS 与 sitemap 是否只包含公开文章，URL 是否只有一层 base 前缀。

## 草稿与发表

- 审稿用 `npm run dev` 查看草稿；`npm run build` 的生产内容不含草稿，不能拿构建产物判断草稿是否完整。
- 发表是作者决定：只有作者显式写 `draft: false` 才公开，审稿通过不自动发表。

## 反馈方式

- 指出具体文件与行为，区分必须修正与可选建议。
- 观点、结构和叙述方式属于作者决定，审稿只提出问题和证据。
- 发表由作者确认；审稿通过不等于自动发布。
